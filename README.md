# GATE CSE Notes

Short, handwritten-style revision notes for the core subjects of the GATE Computer Science & Engineering (CSE) exam, provided as PDF files.

This repository is a fork of [shashankrustagi/GATE-CSE-NOTES](https://github.com/shashankrustagi/GATE-CSE-NOTES), whose description reads: "Short notes I made for GATE CSE subjects during my gate preparation from 2018 to 2021."

## Contents

| File | Subject | Pages |
| --- | --- | --- |
| [`COA NOTES.pdf`](COA%20NOTES.pdf) | Computer Organization & Architecture | 11 |
| [`compiler.pdf`](compiler.pdf) | Compiler Design | 3 |
| [`Computer networks.pdf`](Computer%20networks.pdf) | Computer Networks | 5 |
| [`DBMS.pdf`](DBMS.pdf) | Database Management Systems | 3 |
| [`Digital Logic.pdf`](Digital%20Logic.pdf) | Digital Logic | 4 |
| [`DS ALGO.pdf`](DS%20ALGO.pdf) | Data Structures & Algorithms | 9 |
| [`OS.pdf`](OS.pdf) | Operating Systems | 7 |

All files are in the repository root; there is no code, build step, or tooling.

## How to use

- Open the PDFs directly on GitHub, or
- clone the repository and view them with any PDF reader:

  ```sh
  git clone https://github.com/utkarshpayal/GATE-CSE-NOTES.git
  ```

The notes are condensed summaries meant for quick revision, not a full replacement for standard textbooks.
